# Alt-Sendme - P2P File Transfer Without Cloud Storage

## Overview

Alt-Sendme is a free, open-source file transfer tool that uses peer-to-peer networking to send files directly between devices without cloud storage. Powered by Iroh (modern P2P technology), it provides end-to-end encryption (QUIC + TLS 1.3), resumable transfers, NAT traversal via hole-punching, and works for any file size or format — no accounts, no sign-ups, no upload costs.

## Core Features

- **Direct P2P transfer** — files go straight between devices, no cloud middleman
- **End-to-end encryption** — QUIC + TLS 1.3 with forward/backward secrecy
- **No accounts required** — transfer without sign-ups or personal info
- **Any size, any format** — no file size limits or format restrictions
- **Resumable transfers** — interrupted downloads resume automatically
- **Multi-gigabit capable** — saturates fast connections
- **NAT traversal** — QUIC hole punching with encrypted relay fallback
- **Cross-platform** — Windows, macOS, Linux, Android
- **BLAKE3 integrity** — content-addressed with hash verification
- **23+ languages** — including Ukrainian 🇺🇦

## How It Works

1. **Drop file/folder** → App creates a one-time "ticket" (share code)
2. **Share ticket** → Send via chat, email, text
3. **Recipient pastes ticket** → Transfer begins directly between devices

## Technical Details

### Under the Hood (Iroh)

- **Blobs** — content-addressed storage with BLAKE3 hashes
- **Tickets** — cryptographic tokens containing Ed25519 NodeIds for authentication
- **Hole punching** — QUIC-based NAT traversal, relay fallback if needed
- **Relays** — public relay servers for initial connection, all traffic E2E encrypted

### Stack

- **Pricing Model:** Free and open-source (AGPL-3.0)
- **Platform Support:** Windows, macOS, Linux, Android
- **Framework:** Tauri (Rust + web frontend)
- **P2P Engine:** [Iroh](https://www.iroh.computer)
- **Protocol:** QUIC + TLS 1.3
- **CLI:** Interoperable with [Sendme CLI](https://www.iroh.computer/sendme)

## Notes & Considerations

Windows users may need Microsoft Edge WebView2 Runtime installed. Unlike WeTransfer/Dropbox/Google Drive, files never touch cloud servers — they go directly between peers. Relays only help establish connections; all data is E2E encrypted so relays can't read content. The "ticket" system is more private than broadcasting your IP like traditional P2P. Good alternative for sensitive file transfers or when you don't want to create accounts.
