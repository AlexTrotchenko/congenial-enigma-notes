# btop - Beautiful Terminal Resource Monitor

## Overview

btop is a C++ resource monitor that shows usage and stats for processor, memory, disks, network, and processes — all in a beautiful terminal UI. It's the C++ continuation of bashtop and bpytop with GPU monitoring support (NVIDIA, AMD, Intel), full mouse support, game-inspired menu system, and extensive theming. Cross-platform: Linux, macOS, FreeBSD, NetBSD, OpenBSD (Windows via btop4win).

## Core Features

- **CPU monitoring** — per-core usage with graphs, temperatures, frequencies
- **Memory monitoring** — RAM and swap usage with graphs
- **Disk I/O** — activity and speeds per disk
- **Network** — auto-scaling graphs for network usage
- **Process list** — tree view, filtering, sorting, signals, detailed stats
- **GPU monitoring** — NVIDIA, AMD, Intel (Linux only, requires GPU_SUPPORT build)
- **Full mouse support** — all buttons clickable, scrolling works
- **Battery meter** — for laptops
- **Theming** — 24-bit truecolor, 256-color, TTY modes; many themes included
- **Custom presets** — save and load configurations
- **Game-inspired menu** — easy to navigate UI

## Quick Start Guide

**Install (package managers):**
```bash
# macOS
brew install btop

# Arch Linux
pacman -S btop

# Ubuntu/Debian
apt install btop

# Snap
snap install btop

# FreeBSD
pkg install btop
```

**From source (Linux):**
```bash
git clone https://github.com/aristocratos/btop.git
cd btop
make
sudo make install
```

**With GPU support (Linux):**
```bash
make GPU_SUPPORT=true
```

**Run:**
```bash
btop
```

## Keybindings

| Key | Action |
|-----|--------|
| `h` | Show help menu |
| `Esc` | Close menu/popup |
| `q` | Quit |
| `m` | Open main menu |
| `1-4` | Toggle CPU/Memory/Net/Disk boxes |
| `5-7, 0` | Toggle GPU boxes (1-4) |
| `p` | Pause process list |
| `f` | Filter processes |
| `t` | Tree view |
| `k` | Send signal to process |
| `+/-` | Expand/collapse tree |

## GPU Support

**Requirements (Linux only):**
- **NVIDIA:** Official driver with nvidia-ml library
- **AMD:** rocm_smi_lib
- **Intel:** SYSFS read permission (`make setcap` or `sudo`)

Must compile with `GPU_SUPPORT=true` flag. Pre-built binaries don't include GPU support.

## Themes

Themes stored in:
- System: `/usr/share/btop/themes` or `/usr/local/share/btop/themes`
- User: `~/.config/btop/themes`

Many included themes. Custom themes use same format as bpytop/bashtop.

## Use Cases

- **System monitoring** — watch resource usage in real-time

## Notes & Considerations

btop is the C++ rewrite of bpytop (Python) which was a rewrite of bashtop (Bash). GPU monitoring requires dynamic library loading, so won't work with static builds — compile from source with `GPU_SUPPORT=true`. Intel GPU support added in v1.4.0 but only shows utilization, power, and clock speed. If graph characters look wrong, your font likely missing Braille symbols — try a Nerd Font like Terminess Powerline. The author requests considering donations to humanitarian causes (Ukraine, Save the Children) before donating to the project.
