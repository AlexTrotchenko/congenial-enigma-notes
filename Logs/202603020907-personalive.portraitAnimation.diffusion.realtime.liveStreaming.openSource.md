# PersonaLive - Real-Time Portrait Animation for Live Streaming

## Overview

PersonaLive is a real-time, streamable diffusion framework for generating infinite-length portrait animations from a single reference image. Accepted at CVPR 2026, it can animate a portrait photo using driving video input (facial movements, expressions) for live streaming applications. Features WebUI, TensorRT acceleration (~2x speedup), and streaming strategy that works on 12GB VRAM for long video generation.

## Core Features

- **Real-time portrait animation** — animate still portraits from single reference image
- **Infinite-length generation** — streaming strategy enables unlimited video length
- **Live streaming support** — WebUI for real-time animation streaming
- **TensorRT acceleration** — ~2x speedup with TensorRT conversion
- **12GB VRAM support** — streaming strategy enables long videos on consumer GPUs
- **ComfyUI integration** — available via ComfyUI-PersonaLive node
- **Reference image replacement** — swap reference images during streaming
- **Cross-identity animation** — animate any portrait with any driving video

## Quick Start Guide

**Install:**
```bash
git clone https://github.com/GVCLab/PersonaLive
cd PersonaLive
conda create -n personalive python=3.10
conda activate personalive
pip install -r requirements_base.txt
```

**Download weights:**
```bash
python tools/download_weights.py
```
Or manually from: [HuggingFace](https://huggingface.co/huaichang/PersonaLive), [Google Drive](https://drive.google.com/drive/folders/1GOhDBKIeowkMpBnKhGB8jgEhJt_--vbT), [ModelScope](https://modelscope.cn/models/huaichang/PersonaLive)

**Offline inference:**
```bash
python inference_offline.py
# Options: -L (max frames), --stream_gen (streaming), --reference_image, --driving_video
```

**Online/streaming inference:**
```bash
# Setup WebUI
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.1/install.sh | bash
nvm install 18
source web_start.sh

# Start streaming
python inference_online.py --acceleration xformers  # or tensorrt or none
# Open http://localhost:7860
```

**TensorRT acceleration (optional):**
```bash
pip install -r requirements_trt.txt
python torch2trt.py  # Takes ~20 mins
python inference_online.py --acceleration tensorrt
```
