# gws - Google Workspace CLI for Humans and AI Agents

## Overview

gws is a unified CLI for all Google Workspace APIs — Drive, Gmail, Calendar, Sheets, Docs, Chat, Admin, and more. Built dynamically from Google's Discovery Service, it automatically picks up new API endpoints when Google adds them. Every response is structured JSON, making it perfect for AI agents. Ships with 100+ agent skills and includes an MCP server for integration with Claude, Gemini CLI, VS Code, etc.

## Core Features

- **All Workspace APIs in one CLI** — Drive, Gmail, Calendar, Sheets, Docs, Chat, Admin, and more
- **Dynamic command generation** — built from Google Discovery Service at runtime
- **Structured JSON output** — every response is parseable JSON
- **100+ AI agent skills** — SKILL.md files for every API + 50 curated recipes
- **MCP server** — expose Workspace APIs as MCP tools (`gws mcp`)
- **Gemini CLI extension** — direct integration with Google's Gemini CLI
- **Auto-pagination** — `--page-all` streams paginated results as NDJSON
- **Multiple auth methods** — OAuth, service accounts, access tokens, CI/headless
- **Multi-account support** — switch between work/personal accounts
- **Dry-run mode** — preview requests without executing
- **Schema introspection** — `gws schema <method>` shows request/response schemas
- **OpenClaw compatible** — symlink skills directly to ~/.openclaw/skills/

## Quick Start Guide

**Install:**
```bash
npm install -g @googleworkspace/cli
# or cargo install --git https://github.com/googleworkspace/cli
# or nix run github:googleworkspace/cli
```

**Authenticate:**
```bash
gws auth setup    # Creates GCP project, enables APIs, logs in (requires gcloud)
gws auth login    # Subsequent logins
```

**Use:**
```bash
# List recent Drive files
gws drive files list --params '{"pageSize": 10}'

# Create a spreadsheet
gws sheets spreadsheets create --json '{"properties": {"title": "Q1 Budget"}}'

# Send Chat message
gws chat spaces messages create \
  --params '{"parent": "spaces/xyz"}' \
  --json '{"text": "Deploy complete."}'

# Inspect any method's schema
gws schema drive.files.list
```

## AI Agent Integration

**Install skills (Skills.sh):**
```bash
npx skills add https://github.com/googleworkspace/cli
# Or specific services:
npx skills add https://github.com/googleworkspace/cli/tree/main/skills/gws-drive
```

**OpenClaw setup:**
```bash
ln -s $(pwd)/skills/gws-* ~/.openclaw/skills/
```

**MCP Server:**
```bash
gws mcp -s drive,gmail,calendar  # Expose as MCP tools
```

```json
{
  "mcpServers": {

    }
  }
}
```

**Gemini CLI:**
```bash
gemini extensions install https://github.com/googleworkspace/cli
```

## Authentication Options

| Method | Use Case |
|--------|----------|
| `gws auth setup` | Local desktop with gcloud installed |
| `gws auth login` | Subsequent OAuth logins |
| `gws auth export` → `GOOGLE_WORKSPACE_CLI_CREDENTIALS_FILE` | Headless/CI |
| Service account JSON | Server-to-server |
| `GOOGLE_WORKSPACE_CLI_TOKEN` | Pre-obtained access token |

**Multi-account:**
```bash
gws auth login --account work@corp.com
gws auth login --account personal@gmail.com
gws auth default work@corp.com
gws --account personal@gmail.com drive files list  # One-off override
```

## Notes & Considerations

⚠️ **Not an officially supported Google product.** Under active development — expect breaking changes before v1.0. OAuth apps in testing mode are limited to ~25 scopes; use `gws auth login -s drive,gmail,sheets` to select specific services. Credentials are encrypted at rest (AES-256-GCM) with key in OS keyring. Each MCP service adds 10-80 tools — keep the list focused to stay under client tool limits (typically 50-100). The gws-shared skill includes an install block so OpenClaw auto-installs the CLI if missing.
