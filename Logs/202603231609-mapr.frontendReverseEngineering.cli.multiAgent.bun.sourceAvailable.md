# Mapr - Multi-Agent Frontend Reverse Engineering CLI

## Overview
Mapr is a Bun-native CLI/TUI designed for deep frontend reverse-engineering. It crawls target websites to collect JS bundles, workers, WASM modules, and source maps, then processes them through a multi-agent AI pipeline to generate comprehensive Markdown reports with initialization flows, restored names, inferred call graphs, and security findings.

## Core Features
- **Multi-agent swarm analysis** - 5 specialized agents (scout, runtime, naming, security, synthesizer) analyze code chunks collaboratively
- **Same-origin crawler** - Bounded page count and depth, iframe-aware, discovers all frontend artifacts
- **Artifact discovery** - JS bundles, workers, service workers, WASM, source maps
- **Deterministic extraction** - REST/OpenAPI/GraphQL endpoints, auth flows, captcha, fingerprinting, encryption surface
- **Playwright browser-assisted tracing** - Optional post-hydration DOM, network activity, cookies, storage capture
- **Local RAG mode** - Lexical retrieval for multi-megabyte bundles without context overflow
- **Provider flexibility** - OpenAI, Codex CLI auth, and presets for BlackBox AI, Nvidia NIM, OnlySQ

## Quick Start Guide
1. Install Bun if not already: `curl -fsSL https://bun.sh/install | bash`
2. Install via npx: `npx @redstone-md/mapr --help`
3. For browser-assisted mode: `bunx playwright install chromium`
4. Run interactive mode: `bun start` or headless: `npx @redstone-md/mapr --headless --url <target>`
5. Find results in `mapr-run-<domain>-<timestamp>/` directory

## Use Cases
- Reverse-engineering obfuscated frontend build outputs
- Mapping API surfaces and authentication flows
- Identifying fingerprinting and tracking mechanisms
- Security audits of client-side code
- Understanding initialization sequences in complex SPAs
- CI/batch analysis of frontend artifacts

## Technical Details
- Pricing Model: Free (source-available, restricted license - NOT open source)
- Platform Support: Any platform with Bun runtime; 24-bit truecolor terminal recommended
- Integration Options: Headless CLI mode for CI/automation, configurable via `~/.mapr/config.json`
- Data Export: Markdown report, HTML report, metadata.json, browser-trace.json, raw/formatted artifacts

## Notes & Considerations
- **License warning**: Source-available but NOT open source - restricted reuse/redistribution
- AI-generated outputs (call graphs, symbol names) are inference-based, not authoritative
- Only use on targets you're authorized to analyze
- WASM analysis is summary-based without deeper binary lifting
- Very large or heavily obfuscated bundles depend on model quality
- Requires Bun runtime (not Node.js)
