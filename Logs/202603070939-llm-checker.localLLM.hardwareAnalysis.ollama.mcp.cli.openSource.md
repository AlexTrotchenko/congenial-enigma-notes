# LLM Checker - Hardware-Aware Local LLM Model Selector

## Overview

LLM Checker is a CLI tool that analyzes your hardware and recommends optimal LLM models you can run locally. It scores 200+ models across four dimensions (Quality, Speed, Fit, Context), integrates with Ollama for model management, and includes an MCP server for Claude Code integration. Pure JavaScript with zero native dependencies — works on any Node.js 16+ system.

## Core Features

- **Hardware detection** — Apple Silicon, NVIDIA CUDA, AMD ROCm, Intel Arc, CPU
- **200+ model scoring** — dynamic from Ollama catalog with curated fallback
- **4D scoring engine** — Quality, Speed, Fit, Context weighted by use case
- **Calibrated routing** — generate and apply routing policies from benchmark suites
- **MCP server** — Claude Code integration for AI-assisted model selection
- **Ollama integration** — pull, run, benchmark, compare, cleanup models
- **Enterprise policies** — governance with audit export (JSON, CSV, SARIF)
- **Interactive CLI** — animated panel with command browser
- **Multi-GPU support** — placement advisor for multi-GPU setups
- **Zero dependencies** — pure JavaScript, no native builds required

## Quick Start Guide

**Install:**
```bash
npm install -g llm-checker
# Optional for search features:
npm install sql.js
```

**Basic flow (2 minutes):**
```bash
llm-checker hw-detect                        # Detect hardware
llm-checker recommend --category coding      # Get recommendations
llm-checker ai-run --category coding --prompt "Write hello world in Python"
```

**Calibration (10 minutes):**
```bash
llm-checker calibrate \
  --suite ./sample-suite.jsonl \
  --models qwen2.5-coder:7b llama3.2:3b \
  --policy-out ./calibration-policy.yaml

llm-checker recommend --calibrated ./calibration-policy.yaml --category coding
```

## MCP Server (Claude Code)

**Setup:**
```bash
claude mcp add llm-checker -- llm-checker-mcp
# Or with npx:
claude mcp add llm-checker -- npx llm-checker-mcp
```

**Available MCP tools:**
- `hw_detect` — detect hardware capabilities
- `check` — full compatibility analysis
- `recommend` — top picks by category
- `search` — search Ollama catalog
- `ollama_pull/run/list/remove` — manage Ollama models
- `benchmark` — measure tok/s, load time
- `compare_models` — head-to-head comparison
- `cleanup_models` — find redundant/oversized models
- `project_recommend` — scan codebase, recommend model
- `ollama_monitor` — real-time RAM/model status

**Example prompts for Claude:**
- "What's the best coding model for my hardware?"
- "Benchmark qwen2.5-coder and show me the tok/s"
- "Compare llama3.2 vs codellama for coding"
- "What model should I use for this Rust project?"

## Notes & Considerations

Answers the question "What LLM can I actually run on this machine?" Uses Ollama's full catalog when available, with 35+ curated fallback models. The 4D scoring (Quality, Speed, Fit, Context) is weighted by use case. Calibration generates routing policies that can be applied to `recommend` and `ai-run` commands. Enterprise features include policy validation and SARIF export for CI/CD gates. Hardened for Jetson CUDA detection to avoid false CPU-only fallback.
