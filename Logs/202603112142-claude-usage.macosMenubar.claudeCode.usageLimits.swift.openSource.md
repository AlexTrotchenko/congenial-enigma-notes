# Claude Usage - macOS Menu Bar App for Claude Code Limits

## Overview

Claude Usage is a lightweight macOS menu bar app that monitors your Claude Code API usage limits in real time. Shows your 5-hour session and 7-day usage windows directly in the menu bar with configurable notifications for usage thresholds and limit resets. Zero config — automatically reads credentials from Claude Code CLI.

## Core Features

- **Menu bar indicator** — always-visible usage percentage with brain icon 🧠
- **Session & weekly limits** — track 5-hour session and 7-day usage windows (All Models + Sonnet)
- **Configurable notifications** — usage threshold alerts (50–95%), before-reset reminders (15/30/60 min), on-reset alerts
- **Auto-refresh** — configurable polling interval (1/3/5/10 min) + instant refresh on click
- **Launch at login** — auto-start with macOS
- **Zero config** — reads OAuth credentials from Claude Code CLI automatically (Keychain or ~/.claude/.credentials.json)

## Quick Start Guide

**Option 1: Download Release**
1. Go to [Releases](https://github.com/greenShirtMystery/ClaudeUsage/releases/latest)
2. Download `ClaudeUsage.zip`
3. Unzip and drag to `/Applications`
4. Launch from Applications or Spotlight

**Option 2: Build from Source**
```bash
git clone https://github.com/DaniilKimlb/ClaudeUsage.git
cd ClaudeUsage
brew install xcodegen
xcodegen generate
xcodebuild -scheme ClaudeCodeUsage -configuration Release build
```

**Prerequisites:**
- macOS 13.0+
- Claude Code CLI installed and signed in:
  ```bash
  npm install -g @anthropic-ai/claude-code
  claude  # to sign in
  ```

## Settings

Click gear icon in popover:
- **Usage threshold alert** — on/off + slider (50–95%)
- **Notify before reset** — on/off + time (15/30/60 min)
- **Notify on limit reset** — on/off
- **Auto-refresh interval** — 1/3/5/10 minutes
- **Launch at login** — on/off

## Permissions

| Permission | Required? |
|------------|-----------|
| Keychain (Claude Code credentials) | ✅ Yes (prompted once) |
| Notifications | ✅ Optional |
| Network (api.anthropic.com) | ✅ Yes |
| Full Disk Access | ❌ No |
| Screen Recording | ❌ No |
| Accessibility | ❌ No |

**Keychain tip:** To prevent repeated prompts, add Claude Usage to the Access Control list in Keychain Access for "Claude Code-credentials".

Reads existing Claude Code CLI credentials — no separate login required. If you see repeated Keychain prompts, add the app to the Keychain item's Access Control list.
