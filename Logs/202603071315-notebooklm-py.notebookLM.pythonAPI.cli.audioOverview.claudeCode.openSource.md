# notebooklm-py - Unofficial Python API for Google NotebookLM

## Overview

notebooklm-py is an unofficial Python library that wraps Google NotebookLM's undocumented APIs, providing full programmatic access to features including ones the web UI doesn't expose. Create notebooks, upload sources (URLs, PDFs, YouTube, Google Drive), generate Audio Overviews (podcasts), videos, slide decks, quizzes, flashcards, mind maps, and more. Ships with Claude Code skills for natural language automation.

## Core Features

- **Full notebook management** — create, list, rename, delete notebooks
- **Source management** — add URLs, YouTube, PDFs, text, Word, audio, video, images, Google Drive
- **Chat** — ask questions, conversation history, custom personas
- **Research agents** — web and Drive research with auto-import (fast/deep modes)
- **Audio Overview** — 4 formats (deep-dive, brief, critique, debate), 50+ languages
- **Video Overview** — 9 visual styles (whiteboard, kawaii, anime, etc.)
- **Slide decks** — PDF or PPTX export, individual slide revision
- **Quiz/Flashcards** — export as JSON, Markdown, HTML (not in web UI!)
- **Mind maps** — export hierarchical JSON
- **Data tables** — export as CSV
- **Infographics** — PNG export
- **Claude Code skills** — `notebooklm skill install` for LLM agent integration

## Beyond Web UI

Features available via API/CLI but NOT in NotebookLM web interface:
- Batch artifact downloads
- Quiz/flashcard export (JSON, Markdown, HTML)
- Mind map JSON extraction
- Data table CSV export
- Slide deck as PPTX (editable PowerPoint)
- Individual slide revision with natural language
- Source fulltext access
- Programmatic sharing management

## Quick Start Guide

**Install:**
```bash
pip install "notebooklm-py[browser]"
playwright install chromium
```

**CLI usage:**
```bash
notebooklm login                              # Authenticate (opens browser)
notebooklm create "My Research"               # Create notebook
notebooklm use <notebook_id>
notebooklm source add "https://en.wikipedia.org/wiki/AI"
notebooklm source add "./paper.pdf"
notebooklm ask "What are the key themes?"

# Generate content
notebooklm generate audio "make it engaging" --wait
notebooklm generate video --style whiteboard --wait
notebooklm generate quiz --difficulty hard
notebooklm generate flashcards
notebooklm generate slide-deck
notebooklm generate mind-map

# Download artifacts
notebooklm download audio ./podcast.mp3
notebooklm download quiz --format json ./quiz.json
notebooklm download slide-deck ./slides.pptx
notebooklm download mind-map ./mindmap.json
```

**Python API:**
```python
from notebooklm import NotebookLMClient

async with await NotebookLMClient.from_storage() as client:
    nb = await client.notebooks.create("Research")
    await client.sources.add_url(nb.id, "https://example.com", wait=True)
    result = await client.chat.ask(nb.id, "Summarize this")
    
    # Generate podcast
    status = await client.artifacts.generate_audio(nb.id, instructions="make it fun")
    await client.artifacts.wait_for_completion(nb.id, status.task_id)
    await client.artifacts.download_audio(nb.id, "podcast.mp3")
```

**Claude Code skills:**
```bash
notebooklm skill install
# Then: "Create a podcast about quantum computing"
```

## Notes & Considerations

⚠️ **Unofficial library using undocumented APIs** — not affiliated with Google, APIs may break without notice. Best for prototypes, research, and personal projects. The LinkedIn post by Ivan Nardini (Google DevRel) highlights this as useful despite being unofficial. Requires browser-based authentication on first use. Heavy usage may be rate-limited. Particularly valuable for features the web UI doesn't expose (quiz/flashcard export, PPTX downloads, mind map JSON, batch operations).
